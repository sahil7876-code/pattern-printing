# Pattern Printing Assignment

## Instructions

1. Create a Git repository named **pattern-printing**.
2. Solve each question in a separate Python file.
3. Name the files `pattern1.py`, `pattern2.py`, `pattern3.py`, and continue the same naming pattern up to `pattern12.py`.
4. Complete the questions in the given order.
5. After completing every group of three questions, commit your work to the repository.
6. Your commit messages should clearly mention the questions completed. For example:
   - After Questions 1–3: **Solved 1 2 3**
   - After Questions 4–6: **Solved 4 5 6**
   - After Questions 7–9: **Solved 7 8 9**
   - After Questions 10–12: **Solved 10 11 12**
7. Make sure the output matches the expected pattern. Pay attention to the number of rows, columns, spaces, and symbols.
8. Do not copy solutions. Try to understand the pattern and build the logic yourself.
9. Add comments in every Python file explaining the logic you have used to create that pattern. Comments should describe the purpose of the loops, conditions, and spacing wherever applicable.
